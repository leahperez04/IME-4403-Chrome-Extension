# Conversation Notes user guide

Use Conversation Notes to turn a lecture transcript into personalized notes, flashcards, or a practice quiz.

## Install

1. Open the official Conversation Notes listing in the Chrome Web Store after it is published.
2. Select **Add to Chrome** and review the permissions prompt.
3. Pin the extension from Chrome's Extensions menu and select its icon to open the main page.

The extension requires desktop Chrome 138 or newer and a computer where Chrome's built-in AI is available. Chrome may need to download its model before the first generation.

## Record or paste a transcript

1. Get permission from everyone before recording.
2. Choose the spoken language in the recording controls.
3. Select **Start recording** and allow microphone access if Chrome asks.
4. Select **Pause** if needed, then **Stop & save** when finished.
5. Review and edit the transcript. You can paste a transcript directly instead of recording.

Recording captures microphone audio. It does not capture sound playing in another Chrome tab or elsewhere on your computer. Live speech recognition may be processed through an online Chrome speech service.

## Generate personalized notes

1. Optional: under **Your note style**, select **Upload sample**. You can provide a JPG, PNG, or WebP photo of a notebook page, or a text-based PDF, TXT, or Markdown file.
2. Select **Generate PDF notes**.
3. Review and edit the generated notes in the editor.
4. Select **Download PDF** to export the latest version.

The uploaded sample guides organization and formatting. Lecture facts should come from the transcript. Handwriting can be misread, and the extension does not recreate the exact handwriting or page layout. Generated notes are in English.

## Generate flashcards

1. Make sure the transcript and notes are ready.
2. Select **Generate flashcards**.
3. Click a card to reveal the answer. Use **Previous**, **Next**, or **Shuffle** to study.
4. Select **Export set** to save a text copy.

## Create a practice quiz

1. Make sure the transcript and notes are ready.
2. Select **Create quiz**.
3. Choose an answer and select **Check answer** to see whether it is correct and read the explanation.
4. Move between questions, finish to see your score, or choose **Retake quiz**.

Flashcards and quizzes have separate buttons, so you can create either one independently. Review AI-generated material for accuracy. If you edit the transcript or notes, regenerate the study set to refresh it.

## Switch tabs while generation runs

The extension's main interface opens in a regular Chrome tab, so you can work in other tabs while recording or generating. Keep Chrome open and the computer awake. Keep the Conversation Notes tab open until the current generation finishes; closing it cancels the task.

## Organize saved conversations

In **Conversation library**, select **New folder** to create a folder. Use **Show folder** to filter conversations and **Move to folder** to file the open conversation. Select a saved conversation to return to its transcript, notes, and study tools.

## Privacy and saved work

Audio, transcripts, uploaded samples, notes, folders, flashcards, and quizzes are stored locally by the extension. Note and study-material generation uses Chrome's on-device AI when supported. Uninstalling the extension or clearing its storage may remove saved work, so export important transcripts and PDFs first.
